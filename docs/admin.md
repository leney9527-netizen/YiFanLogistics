# 后台与运价导入

后台在 `/zh/admin`，也可切换到英文或法文。语言切换不改变价格、状态或权限。

管理员可以发布运价、创建员工和修改公司信息。业务员可以录入草稿和处理询价，不能发布，也不能修改员工或公司设置。客户不能打开后台。

## 初始化

1. 在 Supabase 执行两份迁移。
2. 关闭公开注册，并把 Custom Access Token hook 指向 `public.custom_access_token_hook`。
3. 设置 `ADMIN_EMAIL` 和至少 15 位的 `ADMIN_PASSWORD`，运行 `npm run create-admin`。

## 运价

先在港口、船公司和航线中准备主数据。新建运价时填写航线 ID、船公司 ID、有效期和至少一个柜型的销售价。成本价只保存在后台。

发布时只把状态从草稿或待审改为已发布。已发布记录的价格、港口和有效期不能再改。需要调价时新建一个版本。过期记录由 `POST /api/cron/expire` 改为已过期，前台不再展示。已保存的客户报价单使用当时的快照。

## Excel

在「Excel import」下载模板。预览会检查港口代码、柜型价格、日期和中英法语备注是否成套。有错误时不能生成草稿。确认后，服务端使用已保存的预览数据创建草稿，不会直接发布，也不会采用浏览器里临时改过的行。

## 不要写入的内容

不要把未确认的拖车、报关或港杂金额写成正式规则。这些数字必须由业务确认后在费用规则里配置。演示数据必须标记为 demo，生产环境不要设置 `SHOW_DEMO_RATES=true`。
