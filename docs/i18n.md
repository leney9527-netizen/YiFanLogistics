# 三种语言的维护

界面文案在 `messages/zh.json`、`messages/en.json` 和 `messages/fr.json`。三份文件的键必须一致。`npm test` 会检查键是否对齐。

港口、费用、服务说明和常见问题使用同一条业务记录上的中文、英文、法语字段。不要为每种语言复制一条航线或一条价格。船公司名称、柜型代码和港口代码保留官方写法。

报价条件、费用说明和法律相关文字使用人工维护的三个版本。发布前确认三种语言都已填写。当前仓库里的条款是占位文本，仍需业务和法务审核。

语言路由是 `/zh`、`/en`、`/fr`。按钮文字是「中文 / English / Français」。用户主动选择后写入 `NEXT_LOCALE`，已登录用户还会写入账号资料。切换语言保留当前路径和查询参数。

切换语言不改变报价币种。金额和日期按当前语言格式化。截关和开船时间按港口时区显示。

PDF 使用 `assets/fonts/NotoSansSC-Regular.otf`，同一字体覆盖中文、法语重音和货币符号。
